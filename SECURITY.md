# Security Policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's **Security → Report a vulnerability** flow to submit a private
security advisory. Include:

- affected MouseKy version and macOS version;
- mouse model, USB product ID, and firmware version when relevant;
- reproduction steps and expected impact;
- logs or a proof of concept with secrets and personal data removed.

You should receive an acknowledgement within seven days. Please allow time for
investigation and a coordinated release before public disclosure.

## Hardware safety

MouseKy can modify allowlisted onboard-memory fields on explicitly supported
Logitech hardware. Do not experiment with write paths on unknown models,
layouts, or firmware. Reports involving possible device corruption receive
priority.
